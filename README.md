# vertex-sim-core
High-performance Rust simulation engine + GDExtension bridge: memory-safe, deterministic, multi-threaded physics/data simulation for Godot

## Usage
### Prerequisites
- Rust toolchain (>= 1.60)
- Cargo (Rust's package manager)

### Build and Test
To build and test the Rust simulation engine, run the following commands in your terminal:

cargo build && cargo test
